OCRia-nano in the browser

LlamaIndex's OCRia-nano-1 (8.1M parameters) reads a page image into Markdown, with tables, headings and lists. Here it runs in this tab on the CPU, in LiteParse's WebAssembly build, from weights packed to 8-bit integers, so any current browser can run it; nothing is uploaded. It takes images (PNG, JPEG, WebP), not PDFs. The first run downloads the 5.7 MB LiteParse runtime and about 1 MB of weights, plus the options below.

Timings and download

Times are this device's CPU, measured in the page. The LiteParse runtime is fetched once from jsdelivr and cached by the browser.

A detector finds text lines, a router picks a recognizer per line (Latin, world scripts, right-to-left, CJK), and LayoutNet groups lines into tables, headings and lists. Models: OCRia-nano-1 by LlamaIndex, under the OCRia-nano-1 Model License (a modified OpenRAIL-M): free for research and personal use and for organizations under $2M revenue and funding, not for a competing document-parsing service.
