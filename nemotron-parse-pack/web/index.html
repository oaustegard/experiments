Nemotron Parse in the browser

NVIDIA's Nemotron Parse 2.0 reads a document page into Markdown, with a box, a class (title, text, table, picture, header, footer, ...) and a reading order for every block. Here it runs in this tab on your GPU through WebGPU, from weights packed to 4 and 8 bits; nothing is uploaded. It is a 903M-parameter model: the first run downloads several hundred MB, which the browser then keeps, and a dense page takes tens of seconds even on a fast GPU.
