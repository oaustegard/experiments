Test page for diffusion.js. Opened directly it does nothing: node run/test_gpu.mjs _test.html [f32,f32-nosplit,f16,f16-nosplit] loads it in headless Chromium and calls runTests, which runs the chosen runtime variants on the fixtures in test/ and prints each output's error against PyTorch. python3 train/export.py fixture web/test makes the fixtures: a model with random weights, inputs, and PyTorch's outputs for them, so no trained model is needed.
