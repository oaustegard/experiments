Test page for diffusion.js. Opened directly it does nothing. From the experiment directory, first make the fixtures with python3 train/export.py fixture web/test (a model with random weights, inputs, and PyTorch's outputs for them, so no trained model is needed), then run node run/test_gpu.mjs _test.html f32,f16. That loads this page in headless Chromium and prints, for each fixture, the largest error against PyTorch relative to the largest output value. The optional last argument picks runtime variants: f32 or f16 activation storage, and -nosplit to turn off splitting small convolutions across workgroups; all four run if it is left out. Expect about 1e-5 for f32 and 1e-3 for f16.
