Packed OCR

Text detection and recognition from PaddlePaddle's PP-OCRv6 models, with the weights packed to 8-bit integers (tiny 1.6 MB, small 6.3 MB, gzip) and run on hand-written WebGPU kernels in this tab. Nothing is uploaded.

This browser has no WebGPU, so the models cannot run here. Try a current Chrome, Edge or Safari on a computer with a GPU.

Timings and download

Times are this device's GPU and CPU, measured in the page. Download is what the model files weighed on the wire (decoded size in parentheses when it differs).

A detector draws a box round each text line, each line is cropped straight, and a recognizer reads it. Both are PaddlePaddle's PP-OCRv6 (Apache-2.0), rounded to 8-bit integers (the small detector to 7 bits) with one scale per output channel, dequantized once on load and run by WGSL kernels.
