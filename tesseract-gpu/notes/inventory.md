# tessdata LSTM model inventory

This file lists the LSTM line-recognizer models in `tesseract-ocr/tessdata_best`
and `tesseract-ocr/tessdata_fast` (branch `main`, listed 2026-11-19) and shows
that they share one layer sequence. That is why one set of kernels can run every
model: a model differs from another only in layer widths and input height. The
inventory is generated by `run/inventory.py`, with one row per model in
`results/inventory.json`.

## Models per variant

| variant | .traineddata files | with spec | without spec | in `script/` |
|---|---:|---:|---:|---:|
| best | 162 | 160 | 2 | 37 |
| fast | 163 | 160 | 3 | 37 |

The 320 models with a spec are the LSTM recognizers. The five without one are
listed at the end.

## Shared topology

All 320 models with a spec have the same layer sequence:

```
[1,H,0,1 Ct3,3,16 Mp3,3 Lfys N1 Lfx N2 Lrx N2 Lfx N3 O1c1]
```

Only three things vary:

- the input height `H`, 36 or 48;
- the width of the summarising LSTM `N1`, 48 or 64;
- the width of the x-LSTMs `N2`, 64 or 96, and of the last forward LSTM `N3`,
  128, 192, 384 or 512.

The 12 distinct specs are the combinations that occur. The most common spec is
`[1,48,0,1Ct3,3,16Mp3,3Lfys64Lfx96Lrx96Lfx384O1c1]`, with 72 models (43 best,
29 fast). The most common input height is 48, which 172 models use; the other
148 use 36.

## Legend for the spec

| symbol | layer |
|---|---|
| `[1,H,0,1]` | input: batch 1, image height `H`, variable width, 1 channel |
| `Ct3,3,16` | convolution, 3 by 3 kernel, 16 output channels |
| `Mp3,3` | max-pooling, 3 by 3 |
| `Lfys64` | LSTM that runs forward over y and summarises each column, 64 outputs |
| `Lfx96` | LSTM that runs forward over x, 96 outputs |
| `Lrx96` | LSTM that runs reversed over x, 96 outputs |
| `O1c1` | softmax output with CTC decoding |

Numbers after a letter code are sizes: kernel size, channel count or width.
The `1` in `O1c1` is not a class count. The number of output classes comes from
the unicharset and recoder inside each traineddata file: 111 for `eng`
(null class at index 110), 212 for `grc` (null class at index 211).

## Sizes

- LSTM widths (the first number of each `L` layer): from 48 to 512, with the
  distinct values 48, 64, 96, 128, 192, 384 and 512.
- Input heights: 36 for 148 models, 48 for 172 models.

## Models without a spec (5)

- `best/equ` and `fast/equ` are legacy-engine files with no LSTM component. The
  parser reports `component 17 absent`.
- `best/osd` and `fast/osd` are legacy-engine orientation files with no LSTM.
  The parser fails on their header.
- `fast/frk` is a 20-byte file in `tessdata_fast`, so it is not a model. The
  parser reads its first bytes as an entry count and fails.

The inventory lists the 320 LSTM models that the kernels must run: input heights
36 and 48, and LSTM widths from 48 to 512.
