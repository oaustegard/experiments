Read a page with Tesseract, on your own GPU

Drop a scan or a photo of a page. The text lines are found either by PP-OCRv6's text detector, run as WebGPU kernels, or by Tesseract's own page layout. Tesseract's LSTM recognizer, also on WebGPU, reads each line in any of the 320 LSTM models in tessdata_fast and tessdata_best (about 160 languages and scripts, each in both sizes; the legacy-only equ and osd models are not offered). Math is not read for now: math lines are read as text, and a permissively licensed math reader is planned. The page is not uploaded anywhere. Models load on first use from this site, jsDelivr and Tesseract's public repository. It needs a browser with WebGPU; without one the page shows a message and does nothing else.

Text, in reading order

    How it works: PP-OCRv6's detector finds the text lines as a probability map, and layout.js turns that map into line boxes and a reading order (columns by default, or XY-cut). Tesseract's own layout analysis (tesslayout.js, the tesseract.js-core build of Tesseract 5.1) can find the lines instead. Each line is cropped from the page with 3 px of padding and read on the GPU by Tesseract's LSTM recognizer, the same network Tesseract 5 runs on the CPU, ported to WebGPU kernels, with Tesseract's beam search for the text. Math lines are read as text for now.

    Downloads: the detector's weights, about 1.7 MB, come with the page. Tesseract's layout engine (about 2.8 MB) and its English model (about 4 MB) load once, on first use of that option. The recognizer model for the language you pick loads on first use of it, from jsDelivr.
