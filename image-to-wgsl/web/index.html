Images as Shaders

Each picture below is one WGSL fragment shader of a few kilobytes. The shader holds an ordered list of soft, rotated ellipses packed into an integer array, and paints them per pixel. The list was trained so that every prefix is itself a coarser picture, so the shader can paint itself in, and the slider can stop it at any power of two.
