Image to SVG in the browser

k-means on the GPU (WGSL) when WebGPU is available, plain JavaScript otherwise; tracing and output in JavaScript. Nothing is uploaded. "Coarse to fine" paints a few blobs from a 1/8-scale image, then adds detail at 1/4, 1/2 and full scale only where it lowers the error.
