GLiNER runtime check

Test harness for the browser zero-shot NER runtime (ner.js: Ettin-32m text encoder on WebGPU, label encoder and span head in JavaScript). For each packed model in ?pkgs=a,b (directories under models/) it compares token ids, label ids, label vectors, span logits and decoded entities with the NumPy reference's fixtures.json, checks that batched and split runs give the same logits, and, with ?bench=, times the JavaScript stages. Normally driven headless by run/check_web.mjs; results print below and land in window.check.
