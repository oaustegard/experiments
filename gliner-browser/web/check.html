GLiNER runtime check

Test harness for the browser zero-shot NER runtime (ner.js: Ettin-32m text encoder and the span head's per-word layers and scores on WebGPU, label encoder in JavaScript, the span head also in JavaScript as a fallback). For each packed model in ?pkgs=a,b (directories under models/) and each span head in ?heads=gpu,js it compares token ids, label ids, label vectors, span logits and decoded entities with the NumPy reference's fixtures.json, checks that batched and split runs give the same logits, compares the two heads' logits, and, with ?bench=, times the stages per head. Normally driven headless by run/check_web.mjs; results print below and land in window.check.
