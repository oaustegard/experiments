Self-Painting SVG

Pick a picture. It gets traced into flat patches of color, and each patch gets a place on a timeline. The result is a single SVG file that sketches itself in charcoal, paints itself in, goes through night and dawn, then falls apart and starts over. It runs in your browser, and nothing is uploaded. The file plays anywhere an SVG does, with no JavaScript.

Inspired by svjeez by Sai Ashirwad, which compiles hand-written TSX scenes to animated SVG. This one starts from a picture instead. The tracer is the in-browser port of image-to-svg, and the source and write-up are on GitHub.
