What Jev said about itself

Before building this we asked Jev to rate itself and then quizzed it. Asked outright, it rated its music theory basic to competent (1.3 of 3), its Strudel knowledge competent (1.7 of 3) and its ability to pick the next bar competent (1.5 of 3). Asked whether it could predict what a Strudel snippet sounds like, it said yes with probability 0.53. It did better on the quiz than it rated itself.

How it is built

Jev chooses; code does the arithmetic. Every option reaches Jev as a plain description with an energy tag, because it reads intent well and computes pitches badly. Code fills each chord's notes into the pattern, so a bass line written once follows every chord in every key.

Jev settled parts of the design. Asked how often to choose, it picked every bar for the layers and every four bars for harmony and structure (0.81). Asked what the visual should show, it picked a score with one lane per layer next to the rejected options and their probabilities (1.00). It also picked free-text steering plus buttons (0.99). It voted 0.67 to keep a single key and style; this set overrides that and offers six styles and modulation.

Each decision is one call to Jev through the Muninn connector, made one to three bars ahead of the music. If an answer comes back late, the bar holds the previous parts over the new chord, so the music never stops. Random dice uses the same catalog with uniform picks, so you can hear what Jev adds.
