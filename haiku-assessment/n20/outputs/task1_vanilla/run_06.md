# Support Ticket Triage

## Ticket A: charts broken
**Classification: BUG**
A regression where homepage chart colors changed unexpectedly (rainbow → solid) is a product defect with clear reproduction steps and timeline.

## Ticket B: question about export
**Classification: FEATURE_REQUEST**
User is asking about PDF export capability that doesn't currently exist; this is a feature gap or roadmap inquiry.

## Ticket C: URGENT need response
**Classification: SPAM**
External audit firm email requesting form response is not a product support issue; this is misdirected compliance communication and should be forwarded to proper channels, not treated as a product ticket.

## Ticket D: filter weirdness
**Classification: BUG**
A reproducible state management bug where applying filters in one order resets other filters, with a documented workaround indicating underlying logic error.
