Leaf Encoder Lab

A 23 M-parameter search embedder running in this browser with no inference runtime: a 90-line WordPiece tokenizer, a JavaScript forward pass with a 1.3 KB WebAssembly SIMD matmul, and a separate WebGPU version in five WGSL shaders. Both read the same int8 weights. Load the model, check both engines against reference vectors, then time them.
