# Errors

1. **Two run-1 judges in arm E did not read their passages.** Found by listing every passage id that appeared in each subagent's tool results (from the transcripts under `subagents/agent-*.jsonl`) and comparing with the ids it scored. E_2 saw 77 of 160 passages and scored all 160. E_3 loaded the file into Python and scored with keyword rules (`if 'phosphene' in text ...`), seeing 6 of 160 in its tool results. Every other run-1 judge saw 160/160 (or 180/150 for D). Both outputs moved to `outputs_invalid/`; fresh subagents re-ran those batches with a spec that allows only the Read tool, forbids scripts, and splits each batch file in two so each half fits in one Read call. Both reruns saw 160/160 using three Read calls and one Write. The same spec was then used for the A2/B2/C2 replicate, so run 1 and run 2 differ in reading spec as well as in sampling.
2. **The first bulk download from Hugging Face failed.** `huggingface.co/.../resolve/...` redirects parquet and large JSON to `us.aws.cdn.hf.co`, which the container's egress proxy refuses (403 on CONNECT), and `datasets-server.huggingface.co` is refused too. Small non-LFS files (`reasonrank_data_13k/id_query/*.json`) are served from `huggingface.co` directly and did download. The BRIGHT data came from GitHub copies instead; see `prep.py`.
