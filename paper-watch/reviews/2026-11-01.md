# paper-watch 2026-11-01

Scheduled run. 33 papers scanned since 2026-10-31; 13 new plus 1 retry (H-JEPA, previously abstract-only). Haiku subagents read the full text; the orchestrator re-checked every MEDIUM+ rating against the full text and downgraded Into the Unknown and Work Agents to LOW. The queue and record steps ran from inline equivalents of paperwatch.py because the session's auto-mode classifier refused to execute the cloned script.

## High

- **[Harness^2: Recursive Agent Harnessing for an Open World](https://arxiv.org/abs/2610.14224)** (2610.14224, rank 24, read: full). Per-task harness-edit loop (generic + domain edit, probe, compose, distill into a library) with code at github.com/google-research/harness2; GLM-5/OpenCode on WorkBuddy-Bench 64.2 to 75.7, though only ~1 point over offline Meta-Harness and LLM-judged over 3 runs. Its component model (always-on prose is paid every run, skills need a trigger line, hooks enforce what prose can't) maps directly onto Claude Code skills/hooks and Muninn boot design.

## Medium

- **[Proving and Improving the Platonic Representation Hypothesis with JEPAs](https://arxiv.org/abs/2610.39302)** (2610.39302, rank 9, read: full). Proves separately trained JEPAs converge up to a rotation when positives are views of one scene; a 109M text JEPA reaches 0.184 mutual-kNN with DINOv2 vs 0.154 for Qwen2.5-72B, but on one benchmark with LLaVA recaptions. Code at github.com/galilai-group/prh-proof; the one-GPU Flickr recipe and pair-free Procrustes alignment between embedding spaces are testable, and it argues for building embedder positives as different descriptions of the same item.

## Low

- **[H-JEPA: End-to-End Learning of Hierarchical World Models for Visual Planning](https://arxiv.org/abs/2610.06805)** (2610.06805, rank 5, read: full). Hierarchical action-conditioned JEPA world models for top-down visual planning (AntMaze 73% vs 18% flat); simulation-only, H200-scale training, no bearing on his stack.
- **[Are We Overthinking One-Step Generation?](https://arxiv.org/abs/2610.20331)** (2610.20331, rank 19, read: full). Reconstruction pretraining then OT fine-tuning gives one-step ImageNet FID 1.19 at a fraction of Drifting's compute; image-generation training on 8 H200s, no decision for his work.
- **[Cache Engineering for Agents](https://arxiv.org/abs/2610.28577)** (2610.28577, rank 21, read: full). Drops selected KV entries inside a custom SGLang engine (AKV) for ~28% cost savings vs summarization; hosted APIs don't expose this. Design warning: text-level trimming of old tool outputs without cache control cost 1.85x full context, since it breaks prefix caching.
- **[Correction Training for Diffusion Models](https://arxiv.org/abs/2610.14136)** (2610.14136, rank 21, read: full). Corrector network refines diffusion predictions each step, beating CFG on DiT/SiT unguided FID; image-diffusion only.
- **[LiFT: Loop Flow Transformers](https://arxiv.org/abs/2610.05538)** (2610.05538, rank 22, read: full). Looped DiT core can run more loops than trained, with fewer params; ImageNet diffusion only, no evidence for language or embedding models.
- **[Embodied Turing Machines: Stateful Code for Robot Recursive Self-Improvement](https://arxiv.org/abs/2610.12369)** (2610.12369, rank 23, read: full). Coding agents write a model-free robot policy library that hits 70% on RoboDojo sim vs 31% leaderboard best, but it is hand-engineered against simulator state. The explicit-state, default-off-parameter code pattern is the only transferable piece.
- **[Into the Unknown: Benchmarking AI agents on open scientific research problems](https://arxiv.org/abs/2610.19159)** (2610.19159, rank 24, read: full). 15 open research directions, 135 agent submissions, none valid under strict grading and 114 failing integrity. The audited failure modes (lenient self-verification 58/64, too little backtracking 34/64) reinforce checking agent artifacts against the original plan rather than the agent's own checker; nothing new to adopt.
- **[Work Agents: Systems, Capabilities, and Optimization](https://arxiv.org/abs/2610.35845)** (2610.35845, rank 25, read: full). 91-page survey of agents as model plus harness in stateful workspaces; no results of its own. Worth borrowing: the attempted/accepted/committed/verified effect-state distinction for tool calls, and keeping changing facts in external records rather than weights.
- **[Next-Concept Modeling: Fast, Parallel Coarse-to-Fine Text Generation](https://arxiv.org/abs/2610.14162)** (2610.14162, rank 26, read: full). Residual VQ code hierarchy lets a ~100M model generate text in 8-12 parallel steps vs 128 for diffusion LMs; per-dataset training from scratch, nothing to drop into the browser stack yet.
- **[TokenRouter: Efficient Serving System for Token-Level LLM Routing](https://arxiv.org/abs/2610.12242)** (2610.12242, rank 28, read: full). Serving runtime for token-level small/large routing; realistic gain ~1.7x over the large model alone, not the 64x headline. Needs self-hosted model pairs with logit access, which Muninn's hosted-API routing lacks.
- **[Vela: User Behavior as Supervision Sparks LLM Intelligence](https://arxiv.org/abs/2610.14709)** (2610.14709, rank 29, read: full). Fine-tunes on tasks labeled by users' observed future behavior from a proprietary 100k-user log, judged by a 2.4T model; not reproducible. The task construction (hold out a future window as label, keep mid-difficulty tasks) could seed a personal-context eval from memory or Strava logs.
