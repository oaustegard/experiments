- **FlatCake: A Flat KVCache Storage Architecture for LLM Serving** ([2610.38355](https://arxiv.org/abs/2610.38355)), rank 29, 170 upvotes. Write-once, session-contiguous KV-cache storage on DRAM/SSD streamed to GPU via GPUDirect; on a Claude Code trace it reports 94% delivered hit rate and 7.6 s vs 12.2 s mean TTFT against Mooncake at 1.0 QPS. Requires a self-hosted 8xB200 + NVMe + modified SGLang stack and no code is released; the only usable takeaway is keeping shared prompt prefixes byte-stable across subagent calls so provider prefix caches hit.
