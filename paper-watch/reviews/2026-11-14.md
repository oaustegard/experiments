### 28. IQuest-Q1: Advancing Foundation Capabilities for Agentic CLI Systems ([2610.30949](https://arxiv.org/abs/2610.30949))

The benchmark table mixes self-run and vendor-reported scores under different harnesses.

### 30. Embodied First Exam ([2611.12177](https://arxiv.org/abs/2611.12177))
Read: full text. A benchmark of 1,156 simulated-robot tasks for coding agents; reproducing it would take months. Two findings carry over to eval design: the same model scored 34% in Codex vs 22% in Claude Code (partly confounded by an adapter that alters the system prompt), and privileged-access scores (77%) overstate the standard setting (30%), so evals should use the deployed interface and budget.
