# paper-watch 2026-10-31

Seed run, done by hand in chat: the first 20 of the Top 30 posted 2026-10-31. Haiku subagents read each paper, and the orchestrator re-read the abstract-only cases with a fresh agent.

## Medium

- **[Jeva: System One Models from First Principles](https://arxiv.org/abs/2610.18773)** (2610.18773, rank 4, read: full). Permutation-invariant option scorer with null outcome; beats Jev-1.13.0 (likely decide's lineage) on BANKING77 K=8 92.05 vs 86.14, null AUROC 98.7 vs 93.6. No weights stated in paper; possible BANKING77 contamination. Test head-to-head vs decide on Typed Decisions + BANKING77; borrow coverage gate and cached per-option K/V.
- **[Trial by Trace: Benchmarking AI Agent Harnesses for Reliability and Failure Attribution](https://arxiv.org/abs/2610.32285)** (2610.32285, rank 18, read: full). 7-part harness taxonomy as audit checklist; 31% of task successes violate a harness criterion. Code TraceLite-AI/TraceTrial-Bench.

## Low

- **[Hybrid Reasoning Agents](https://arxiv.org/abs/2610.18861)** (2610.18861, rank 1, read: full). Latent reasoning cuts agent tokens 35-55%, but only via RL fine-tuning of open models; code at togethercomputer/HybridAgent, no weights.
- **[A Fix for Softmax and Cross-Entropy](https://arxiv.org/abs/2610.31642)** (2610.31642, rank 2, read: full). Corrected low-precision softmax/CE and soft-target distillation loss; toy experiments only; relevant only if writing custom bf16 distillation losses.
- **[H-JEPA: End-to-End Learning of Hierarchical World Models for Visual Planning](https://arxiv.org/abs/2610.06805)** (2610.06805, rank 6, read: abstract). Hierarchical latent world models for visual planning; robotics/sim training.
- **[Towards Looped Models Done Right, Part II: Rethinking at Fixed Points](https://arxiv.org/abs/2610.06833)** (2610.06833, rank 7, read: full). Looped 1.6B ~1/3 the weight bytes of equal-depth untied at equal FLOPs; terminal KV sharing 3x smaller cache at <=0.85% ppl. No checkpoints; gains within seed noise. Code ifm-ai/xllm-loop.
- **[Why is AI-generated language so hard to understand?](https://arxiv.org/abs/2610.29162)** (2610.29162, rank 8, read: full). Frontier models overuse psycholinguistically hard constructions; descriptive, nothing to adopt.
- **[AI Models Can Provably Hide Arbitrary Capabilities](https://arxiv.org/abs/2610.13928)** (2610.13928, rank 10, read: full). Encrypted capability lockers survive SFT/LAT/GCG; supply-chain threat, no tested mitigation. Clean evals of open-weight models cannot rule out hidden triggers.
- **[MemT-1.0: Towards Memory-Native Evolution](https://arxiv.org/abs/2610.26825)** (2610.26825, rank 11, read: full). Memory-in-weights trails same-backbone DenseRAG by 9.5 pts avg (LongMemEval 32.6 vs 70.8) -- supports external memory design. Code MemTensor/MemT-1.0, HF collection MemTensor/memt-1.
- **[MiMo-V2.6: Scaling Reinforcement Learning Towards Self-Improvement](https://arxiv.org/abs/2610.11959)** (2610.11959, rank 13, read: full). RL scaling tech report; mentions MiMo-V2.6-Distill-Qwen-9B but no release link found.
- **[VideoJev: System One Model for Video Understanding and Interaction](https://arxiv.org/abs/2610.18615)** (2610.18615, rank 14, read: full). Video interval/MC scoring with shared-prefix caching; no video pipeline in stack.
- **[Generative Representation Learning for Scalable Latent Tokenization](https://arxiv.org/abs/2610.20533)** (2610.20533, rank 17, read: full). Image latent tokenizer from diffusion PMI; not text retrieval. Code AlanBaade/repr.
- **[OR-License: Evaluating LLM Agents as Real-World Operations Research Practitioners](https://arxiv.org/abs/2610.24087)** (2610.24087, rank 19, read: full). Infeasible deliveries are most of the gap to experts; reinforces hard-constraint checks before agent delivery.
- **[Self-Retrospection Distillation](https://arxiv.org/abs/2610.08077)** (2610.08077, rank 20, read: full). RLVR training add-on; prompt-only variant showed little effect.
