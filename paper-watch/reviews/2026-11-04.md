## MEDIUM

### 28. Thinking Inertia: LLMs Keep Thinking When Told Not To ([2610.11765](https://arxiv.org/abs/2610.11765))
Native no-thinking modes give answer-only output on Boolean tasks (80-100% empty-thinking rate) but almost never on open-ended ones. Strict answer-only prompting on open-ended tasks raises empty-thinking to about 40% and costs about 15 accuracy points; explicit inference still appears in 62% of responses (down from 99.69%). For cheap-model gates and subagent calls, pose a closed answer set instead of suppressing reasoning on an open question. Numbers verified in the body text; no code released.

## LOW

### 24. Evolving Agent Teams ([2610.36848](https://arxiv.org/abs/2610.36848))
A supervisor agent restructures a Claude Code agent team when it plateaus. MLA decode reaches 0.74x of FlashInfer against 0.51x for the Claude Code baseline at matched tokens, with every agent on Opus 4.6, two runs per setting and no cost comparison. The transferable piece is a mandated cross-team synthesis document that every subagent reads. Code: https://github.com/caoshiyi/EAT

### 29. RSI-Anything: Unlocking Recursive Self-Improvement with World Models ([2610.13912](https://arxiv.org/abs/2610.13912))
A small calibrated predictor ranks candidate patches or actions before execution. On CodeContests it lifts hidden-test success from 26.0% (random) to 29.2% (95% CI +0.17 to +5.50 points); the other domains show gaps within noise. This is reranking, which the existing `decide` tool already covers. Code: https://github.com/Gen-Verse/RSI-Anything
