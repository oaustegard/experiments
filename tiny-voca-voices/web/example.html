tinyvoca.js example

This is the smallest page that speaks in a saved tiny-voca voice. Choose a .voice.json file from the Voice Tuner (or leave it empty for stock F2), type some text and press Speak. View source: it is about 60 lines.

Query parameters: ?text=Hello fills the text, &voice=URL loads a voice file from a URL (the host must allow cross-origin requests; GitHub Pages and raw.githubusercontent.com do).
