tiny-voca Voice Tuner

Build your own voice for tiny-voca, a 4.5M-parameter text-to-speech model with two stock voices, F2 and M2, and save it as a file to use in your own pages and scripts. Everything runs in this page: the model is 10 MB and speaks about 16× faster than real time on one WebAssembly (CPU) thread.

Once it has loaded, pick a preset and press Speak, then drag a slider: each release speaks the text again in the new voice.

A voice file (.voice.json, about 4 KB) holds the voice itself: the two embeddings and the six controls the model reads. Play it in your own page or script:

<script src="https://austegard.com/experiments/tiny-voca-voices/web/tinyvoca.js"></script>
<script type="module">
  const tts = await TinyVoca.load();
  const voice = await (await fetch("my-voice.voice.json")).json();
  const audio = await tts.speak("Hello there.", voice);   // Float32Array, 24 kHz
  const wavBlob = TinyVoca.wav(audio);
</script>
# Python: pip install onnxruntime numpy soundfile git+https://github.com/n4ze3m/dizione

Phonemes the model read

—

Voice embedding. The model learned one 192-number vector per voice, at the phoneme and the frame level. The first slider walks between F2 (0) and M2 (1) and past them. The four axes point away from that line in fixed random directions; 1.0 is as far as F2 is from M2. Each hint says what that axis did at +1 on F2 in tests. Their combined distance off the line (shown under the axes) is what matters: every random voice up to 1.13 stayed clear, one axis at a time at ±1 lost a word once in 32 tries, and past about 1.15, 6 of 8 random voices garbled a word. "Surprise me" stays within 0.9.

Vocal tract and texture. The waveform comes from a pulse train and noise, each shaped by a filter the network predicts every 10.7 ms. Formant scale resamples that filter along frequency: below 1 sounds larger and older. Brightness tilts the voiced filter, breath raises the noise filter.

Every preset transcribed exactly in Whisper, a speech recognizer. So did the ends of the other sliders, except speed ×2, which slurred one word. Method and measurements: experiments/tiny-voca-voices.
