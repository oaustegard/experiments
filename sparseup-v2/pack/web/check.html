SparseUp v2 in WebGPU: accuracy and speed check

Runs the 47 fixture texts (fixtures/parity.json) through the browser encoder and records each sparse vector, so check.py can compare them with the PyTorch reference, then times one text at 128 and at 512 tokens. Open it as /sparseup-v2/pack/web/check.html?pack=int8 from a server at the experiments repo root, with the pack built by pack.py; add &reps=10 for more timing runs.
