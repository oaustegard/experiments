SparseUp in the browser

A learned sparse retriever: each text becomes a handful of weighted vocabulary terms, including terms it never contains. A document's score for the query is the dot product of the two term lists: the sum, over shared terms, of query weight times document weight. Higher means more relevant. The page needs WebGPU and loads a 151 MB weight pack from this server before the button turns on.

term in the text   expansion term (not among the text's own tokens) The model merges each word's spelling variants (capitalized, lowercase, with or without a leading space) into one term, so a word that is in the text can still be marked as expansion when its merged form is a different token. Model Linkup-Platform/linkup-sparseup-embed-v2 (apache-2.0). It runs on WebGPU compute shaders written for this page, with weights stored as 8-bit integers (int8), and needs no ML library.
