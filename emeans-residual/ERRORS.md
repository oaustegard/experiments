# Errors

1. **The control threshold was wrong twice.** `residual_bench.py` checks that its K = 1 path equals remex's centred search. The first threshold was a maximum score difference under 0.005; the full run measured 0.0053 with identical recall and stopped. The second was the 99.99th percentile under 1e-4, which failed at 2 bits (1.15e-4). The cause in both cases: the script rotates a direction derived in float64 and remex one cast to float32, so 7 to 39 rows per 100,000 have one coordinate on the other side of a cell boundary, and a flipped code shifts that row's score for every query. The control now tests the median difference (1.2e-7), the share of rows that differ at all (under 0.04%) and equal recall. Caught by the assertion itself; cost two reruns of about a minute each. No effect on any reported number.
2. **The smoke test did not predict the full run.** On 20,000 rows and 200 queries at K = 64 the residual gain at 1 bit looked like +0.02 with every source within noise, which is what the full run found for the sources but understated how far random points fall behind (0.798 against 0.858).
