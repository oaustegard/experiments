## Getting started

Tilt Rally runs in a phone browser at https://austegard.com/fun-and-games/tilt-rally.html. You steer by tilting the phone, so it needs a phone with a motion sensor.

### Before you start

1. Lock your phone's screen rotation in portrait. The game tells you when to turn the phone to landscape, so the system rotation only gets in the way.
2. Open https://austegard.com/fun-and-games/tilt-rally.html.
3. On iOS, allow motion access when the browser asks. The game cannot read the tilt without it.

### Choosing a race

The first screen is held in portrait. Use it to choose:

- **Track:** Fjord, Quarry or Ring
- **Laps**
- **Difficulty**

Then tap **Start engine**.

### Starting the race

When the game prompts you, turn the phone to landscape and hold it the way you want to drive. The game zeroes the steering at the moment the start lights go out, so whatever tilt the phone has then counts as straight and neutral. Hold it steady until the lights go out.

### Controls

| Tilt | Effect |
|---|---|
| Left or right | Steer |
| Top of the phone away from you | Accelerate |
| Top of the phone towards you | Brake |
