## Getting started

Open https://austegard.com/fun-and-games/tilt-rally.html on a phone that has a motion sensor. You steer by tilting the phone, and the game sets its straight-ahead position from how you hold the phone when the start lights go out.

### Before you start

- Lock screen rotation in portrait. The game asks for landscape itself and shows a prompt when it is time to turn the phone, so automatic rotation would get in the way.
- On iOS, allow motion access when the browser asks for it. If you don't, the game cannot read the tilt.

### Options

The first screen is in portrait and holds the options:

- **Track:** Fjord, Quarry or Ring
- **Laps**
- **Difficulty**

### Calibration

When the prompt appears, turn the phone to landscape and hold it in your normal driving position. The game zeroes the tilt at the moment the start lights go out, so whatever angle you hold then counts as straight and neutral throttle.

### Controls

| Tilt | Action |
| --- | --- |
| Left / right | Steer |
| Top of the phone away from you | Accelerate |
| Top of the phone towards you | Brake |
