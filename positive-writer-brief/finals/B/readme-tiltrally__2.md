## Getting started

Open https://austegard.com/fun-and-games/tilt-rally.html on a phone that has a motion sensor. You steer by tilting the phone. The game sets its straight-ahead position from how you hold the phone when the start lights go out.

### Before you start

- Lock screen rotation in portrait. The game asks for landscape itself, with a prompt to turn the phone when it is time, so automatic rotation would get in the way.
- On iOS, allow motion access when the browser asks for it. If you don't, the game cannot read the tilt.

### Options

The first screen is held in portrait and has the options: the track (Fjord, Quarry or Ring), the number of laps and the difficulty.

### Calibration

When the game prompts you to turn the phone, turn it to landscape and hold it in your normal driving position. The game zeroes the tilt at the moment the start lights go out, so the angle you hold then counts as straight ahead and neutral throttle.

### Controls

| Tilt | Action |
| --- | --- |
| Left / right | Steer |
| Top of the phone away from you | Accelerate |
| Top of the phone towards you | Brake |
