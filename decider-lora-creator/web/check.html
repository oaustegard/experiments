Creator checks

Correctness checks for the decision spike creator. Needs WebGPU; serve from the experiments repo root (node run/check.mjs check). Each check reports ok. (1) the page's prompt builder against the token ids that the training code produces for the demo (web/fixtures.json, from run/make_fixtures.py); (2) the head-only trainer's logits (frozen encoder, decision head in JS) against adapter-library's NumPy reference, to under 1e-3; (3) a short head-only training run on the invoice demo (train loss must fall), and the exported spike reloaded into a fresh inference engine (same top option on every test case). Checks (4)–(6) run the WebGPU LoRA trainer from ettin-wgsl-train: its logits against the head-only path, a weight round trip, and a short LoRA run. ?n=16&test=6&epochs=3 (the defaults) set labelled cases, test cases and epochs, and lora=0 skips (4)–(6); on a software GPU this takes 10–30 minutes.
